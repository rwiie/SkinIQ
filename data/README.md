# Data

Datasets are public Kaggle datasets (proposal 3.5) and are **not committed**.

| Folder | Contents |
|---|---|
| `raw/skin_type/` | Facial skin type images: `normal/`, `oily/`, `dry/`, `combination/` |
| `raw/skin_condition/` | Facial skin condition images, one folder per condition |
| `raw/products.csv` | Korean skincare product dataset (name, brand, category, ingredients) |
| `processed/` | Resized images, 70/15/15 splits, standardized product file |

Record each dataset's Kaggle URL and licence here once downloaded.
